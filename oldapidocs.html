Introduction

Welcome to the Payable Payment Gateway API. This documentation provides a comprehensive guide to integrating our secure payment solutions for deposits (Pay-In) and withdrawals (Pay-Out).

Version: 2.1
Base URL: https://gaurpay.site

All requests must be made over HTTPS with Content-Type: application/json.

Authentication

We use Header-Based Authentication with HMAC-MD5 signatures. Every API request must be authenticated.

Required Headers

Header Example Description
x-merchant-id 550e8400-e29b... Your unique Merchant UUID
x-signature A1B2C3D4E5... MD5 hash signature

Signature Generation

Formula
  1. Sort all body parameters alphabetically by key (ASCII)
  2. Remove empty values and sign field
  3. Join with & in key=value format
  4. Append &secret=YOUR_SECRET_KEY
  5. Hash using MD5 and convert to uppercase

Node.js Example

const crypto = require('crypto');

function generateSignature(params, secretKey) {
    const filtered = {};
    Object.keys(params).forEach(key => {
        if (key !== 'sign' && params[key] !== '' && params[key] != null) {
            filtered[key] = params[key];
        }
    });
    const sorted = Object.keys(filtered).sort();
    const query = sorted.map(k => `${k}=${filtered[k]}`).join('&');
    const str = `${query}&secret=${secretKey}`;
    return crypto.createHash('md5').update(str).digest('hex').toUpperCase();
}

PHP Example

function generateSignature($params, $secretKey) {
    $filtered = array_filter($params, fn($v) => $v !== '' && $v !== null);
    unset($filtered['sign']);
    ksort($filtered);
    $parts = [];
    foreach ($filtered as $k => $v) $parts[] = "$k=$v";
    $str = implode('&', $parts) . "&secret=$secretKey";
    return strtoupper(md5($str));
}

Error Codes

Standard response codes returned by the API.

Code Meaning / 含义
1 Success / 成功
0 Failed / 失败
-1 Invalid signature / 签名错误
-2 Missing parameters / 缺少参数
-3 Insufficient balance / 余额不足
-4 Order not found / 订单不存在

Status Values / 状态值

Status Meaning / 含义
pending Awaiting payment / 等待支付
processing Being processed / 处理中
success Completed successfully / 成功完成
failed Failed / 失败

Create Pay-In Order / 创建充值订单

Generate a payment link to collect funds from a user.

POST/api/payin/create

Parameter Type Description
orderId String Required Unique Order ID (Max 64 chars) / 唯一订单号
orderAmount Number Required Amount to collect (Min ₹100) / 收款金额
callbackUrl String Required Webhook URL for notifications / 回调通知地址
skipUrl String Optional Redirect URL after payment / 支付后跳转地址
param String Optional Custom data returned in callback / 自定义回传数据

Example Request

{
    "orderId": "MC001-998877",
    "orderAmount": 500,
    "callbackUrl": "https://mysite.com/webhook",
    "skipUrl": "https://mysite.com/success"
}

Success Response

{
    "code": 1,
    "msg": "Order created",
    "data": {
        "orderId": "MC001-998877",
        "id": "e0b5...88",
        "orderAmount": 500,
        "fee": 25,
        "paymentUrl": "https://gaurpay.site/pay/DF-123456",
        "deepLinks": {
            "upi_phonepe": "phonepe://...",
            "upi_paytm": "paytmmp://...",
            "upi_gpay": "tez://upi/pay?pa=...",
            "upi_scan": "upi://pay?..."
        }
    }
}

Pay-In Callback / 充值回调

We send a POST request to your callback URL when payment status changes.

Callback Parameters / 回调参数

Field Type Description
status Number 1 = Success, 0 = Failed / 1成功 0失败
amount Number Net amount after fees / 扣费后到账金额
orderAmount Number Original order amount / 原始订单金额
orderId String Your merchant order ID / 商户订单号
id String Gateway transaction ID / 网关交易ID
utr String Bank reference number / 银行流水号
param String Your custom parameter / 自定义回传参数
sign String MD5 signature / MD5签名

Example Callback / 回调示例

{
    "status": 1,
    "amount": 475.00,
    "orderAmount": 500.00,
    "orderId": "MC001-998877",
    "id": "uuid-v4-string",
    "utr": "123456789012",
    "param": "custom-data",
    "sign": "A1B2C3D4E5F6..."
}
Important / 重要: You must respond with plain text OK to acknowledge. We retry up to 5 times if not received.
必须响应: 收到回调后需返回纯文本 OK。未收到确认将重试5次。
